Your first call: 8 lines

from groq import Groq

client = Groq(api_key=GROQ_API_KEY)          # never paste the key in shared code

reply = client.chat.completions.create(
    model="openai/gpt-oss-20b",
    messages=[{"role": "user", "content": "Who are you?"}],
)
print(reply.choices[0].message.content)

Act 3 / Messages

A chat is a list of messages

system

The rules. Who the bot is, what it must and must not do.

Written by you, the developer.

user

What the student typed.

assistant

What the model said before.

You send it back so it "remembers".
Act 3 / The system prompt

Same question, different system prompt

systemYou are a helpful assistant.
studentI'm stressed about exams. Help?
replySure! Here are 10 tips for exam stress, plus a recipe…
systemYou are JAIN's student helpdesk. Answer in 2 sentences. If unsure, say so and give the office contact.
studentI'm stressed about exams. Help?
replyJAIN has a student counselling centre that can help. Want to know how to reach it?

The system prompt is the cheapest way to change behaviour.

"We asked for a helpful helpdesk. If we prompted it to be a realistic university admin counter, the reply would be: go to Block B, get a stamp from the coordinator, and come back after lunch."
Act 3 / Memory is a trick

The model remembers nothing

"call_1": [{"role": "system","content": "You are JAIN's student helpdesk."},{"role": "user","content": "I'm stressed about exams. Help?"}]
"call_2": [{"role": "system","content": "You are JAIN's student helpdesk."},{"role": "user","content": "I'm stressed about exams. Help?"},{"role": "assistant","content": "JAIN has a counselling centre. Want its contact?"}]
"call_3": [{"role": "system","content": "You are JAIN's student helpdesk."},{"role": "user","content": "I'm stressed about exams. Help?"},{"role": "assistant","content": "JAIN has a counselling centre. Want its contact?"},{"role": "user","content": "Yes, please."}]

Every call sends the whole conversation. Long chats cost more and eventually overflow the context window.
