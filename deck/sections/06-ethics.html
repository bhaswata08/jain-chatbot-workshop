Act 6 / Rules for today

Three rules

Guard your key

An API key is a password with a bill attached.

Never in GitHub, screenshots or WhatsApp groups.

No private data

Don't paste marks, phone numbers or Aadhaar into a hosted LLM.

You don't control where it goes.

Show sources

Wrong refund advice = a student loses money.

If it can't cite, it shouldn't answer.
